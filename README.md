## 🌟 المميزات الرئيسية
1. **رصيد وهمي آمن 100% (10 SOL):** لا يتطلب إدخال أي مفاتيح خاصة (Private Keys) ولا يمس أموالك الحقيقية.
2. **رادار قنص لحظي (Solana Sniping Radar):** فحص أحدث العملات فورياً من شبكة سولانا (Pump.fun / Raydium).
3. **فلاتر أمان صارمة (Anti-Rug Gates):**
   - فحص السيولة الدنيا ($6,000+).
   - فحص حجم تداول الـ 5 دقائق ($5,000+).
   - فحص ضغط الشراء (Buy Ratio > 50%).
4. **إدارة مخاطر آلية:**
   - جني أرباح تلقائي (Take Profit عند +40%).
   - وقف خسارة تلقائي (Stop Loss عند -15%).
   - وقف خسارة متحرك (Trailing Stop لتأمين الأرباح عند القمم).
5. **تكامل مباشر مع GMGN.ai:** زر مباشر أمام كل عملة لفتح الرسم البياني والمحفظة على GMGN مع كود الإحالة الخاص بك.
6. **لوحة تحكم ويب تفاعلية حديثة:** تعمل على المتصفح المحلي `http://127.0.0.1:8000` وتحدث الأسعار والأرباح كل 3 ثوانٍ.
